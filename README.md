# PRODIGY_ST_05

This project focuses on automating the end-to-end checkout process of an e-commerce website using Selenium WebDriver with Python.
The automation validates key user interactions such as logging in, adding products to the cart, completing checkout steps, validating forms, selecting payment options, and confirming a successful order.


**Objectives**

Automate the complete checkout workflow of an e-commerce application

Verify smooth navigation between checkout pages

Validate mandatory fields and conditions during checkout

Confirm successful order placement

Capture screenshots as execution evidence

**Application Under Test (AUT)**

Parameter	Details
Application Name	Automation Practice
URL	http://www.automationpractice.pl/index.php

**Test Scenarios**

Positive Test Scenarios

User login with valid credentials

Product successfully added to the shopping cart

Navigation through all checkout pages

Successful payment process

Order confirmation message verification

Validation Scenarios

Mandatory Terms & Conditions validation

Page transition verification at each checkout stage
